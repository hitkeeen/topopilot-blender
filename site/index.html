TopoPilot

Local-first mesh diagnosis for AI-generated assets, with an optional AI layer and a Blender workflow that keeps checks visible and repeatable.

⬇️ Download

A small, inspectable starting point

Diagnose before editing

Check boundaries, non-manifold edges, degenerate faces, and basic density metrics without changing the mesh.

Run locally

The CLI and sample fixture work offline. External models and provider adapters are optional and explicit.

Keep judgment in the loop

A report supports artist and engine review. It does not promise ideal topology or replace visual validation.

Workflow preview

TopoPilot is a starter project. Complex meshes require manual review, and final UV, LOD, material, deformation, and engine checks remain application-specific.
